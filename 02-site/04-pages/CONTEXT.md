# 04-pages

**Job:** build real pages from approved content.

**Inputs:** approved pieces from `01-content/`; the shell and components from `03-shell/`.

**Process:**

1. Build each page in the shell, using its components and tokens only.
2. Place Danny's text exactly as approved; never edit it.
3. Check each page at phone and desktop widths.
4. Update the site map when a page, layout, or component is added.

**Outputs:** pages ready for `03-deploy/`.

**Checkpoint:** Danny approves each page before it goes to `03-deploy/`.

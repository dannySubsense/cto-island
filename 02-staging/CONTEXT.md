# 02-staging

**Job:** turn one inbox item into a publish-ready package without changing its words.

**Inputs:** one item from `01-inbox/`.

**Process:** create a folder named for the piece (naming convention in `/CONTEXT.md`) holding:

- the content, copied unchanged from the inbox
- its metadata: title, type, date, and image
- the LinkedIn post text, which Danny writes or approves

Show Danny the package. It moves on only with his publish OK.

**Outputs:** an approved package, ready for `03-site/`.
